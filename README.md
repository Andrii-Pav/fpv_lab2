# Лабораторна робота №2: політ дрона до заданої точки (Gazebo + ArduPilot SITL + ROS 2)

Варіант 14: dx = 6.4, dy = 0.2. Ціль: (x0 - 6.4, y0 - 0.2).

Політ виконується у світі `maze.sdf` з урахуванням обходу перешкод (стіна Wall_9 зміщена під землю).

## Результат польоту

| Етап | x, м | y, м |
|---|---|---|
| Старт | 0.000 | 0.000 |
| Ціль | -6.400 | -0.200 |
| Перед посадкою | -6.336 | -0.200 |

Похибка досягнення цілі: 0.064 м.

## Структура проєкту

- `src/fpv_lab2` - ROS 2 пакет: `flight_test` (початковий приклад), `target_flight` (власний алгоритм польоту до точки)
- `scripts` - скрипти запуску, зупинки, збірки (`start_all.sh`, `start_sim.sh`, `run_flight.sh`, `stop_sim.sh`, `build.sh`)
- `report` - лог польоту, результати, версії ПЗ

## Запуск

Потрібні Ubuntu 22.04, ROS 2 Humble, Gazebo Harmonic і ArduPilot SITL у `~/ardu_ws`.
Збірка пакета: `scripts/build.sh`. Запуск симуляції: `scripts/start_sim.sh`. Зупинка: `scripts/stop_sim.sh`.
